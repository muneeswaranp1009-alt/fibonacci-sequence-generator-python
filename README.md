Fibonacci Sequence Generator

Beginner-friendly Python project which generates Fibonacci sequence of numbers depending on terms entered by the user.

This program uses a Python function with a list to generate the Fibonacci sequence which is then printed out on the terminal.

## Features

- Fibonacci series generator with list

- Calculates next fibonacci number from the previous two

- Warning message for invalid number of terms

- Easy to run Python script

## Technologies

- Python

## Usage

The program utilizes a function called `fib_gen(n)` to calculate and generate the fibonacci sequence. With that being said, the program will:

1. Ask the user for the how many terms to print

2. Create a list of the fibonacci sequence using a `for` loop

3. Print the fibonacci sequence

## Example Output

-----------Fibonacci Generator----------

How many terms you want print: 7

First 7 Fibonacci numbers: [0, 1, 1, 2, 3, 5, 8]

## How to Run

1. First make sure to install Python in your machine

2. Clone this repo

3. Make sure you're in the project's directory

4. Run the following command in terminal

python Fibnoaci_genrator.py

5. Follow the instruction in the terminal to enter how many terms you want to print
